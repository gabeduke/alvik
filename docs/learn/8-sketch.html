🙀 Teach it a trick

Time to write a program of your own. A sketch is a small program that shows up as a new colour in the robot's menu. You will read one, then write one: a scaredy cat that backs away when something comes close.

🧰 You need

  • The robot, a USB-C cable and the computer from lesson 1.
  • Something to type code in. Arduino Lab for MicroPython is enough.

▶️ Read one first

  1. On the 🔧 Update the robot page, add 🐕 Follow me and update the robot.
  2. On the robot, tap ⬆ until the lights are yellow, then ✓. Hold your hand in front of it and walk it around like a puppy.
  3. Now read it. The whole program is one function:
def run(alvik):
    readings = alvik.get_distance()                  # cm, or None if a sensor has no reading yet
    readings = [SEE_CM + 1 if d is None else d for d in readings]
    closest = min(readings)
    where = readings.index(closest)                  # 0 = far left ... 2 = middle ... 4 = far right

    if closest > SEE_CM:
        lights(alvik, WAITING)
        alvik.brake()
    else:
        lights(alvik, FOLLOWING)
        speed = max(-MAX_SPEED, min(MAX_SPEED, closest - NEAR_CM))   # too far: forward, too close: back up
        turn = (2 - where) * TURN                                    # positive = turn left
        alvik.drive(speed, turn)

    sleep_ms(50)
    return 1

Find the closest of the five readings. If it is on the left, turn left. If it is further than the puppy likes, drive forward; if it is nearer, back up. That is all a puppy needs.

alvik.drive(speed, turn) is the one command for moving: a speed in cm/s (negative is backwards) and a turn in degrees per second (positive is left).

🔍 How a sketch works

A sketch is a folder with three files in it:

FileWhat it is
scaredy_cat.pyThe program. It must have a function called run(alvik).
sketch.jsonA label: its name, an emoji, a line about it, and the colour of its menu light.
README.mdA note for people: what it does, its lights and buttons.

The menu calls run(alvik) again and again, many times a second, until someone presses ✗. So run does one small step each time: look, decide, move, done. Don't write a loop that goes on for ever inside it, or ✗ will stop working.

When the robot starts, it looks in its /sketches folder, reads each sketch.json, and adds a colour to the menu for each one. If your program crashes, the lights flash red three times and the menu comes back. Nothing breaks.

✍️ Write the scaredy cat

Make a folder called scaredy_cat and type these two files into it. Typing it yourself is slower than copying, and you will understand it better.

scaredy_cat.py

from time import sleep_ms

TOO_CLOSE_CM = 15    # closer than this is scary
BACK_SPEED = 8       # cm/s

CALM = (0, 1, 0)
SCARED = (1, 0, 0)


def lights(alvik, rgb):
    alvik.left_led.set_color(*rgb)
    alvik.right_led.set_color(*rgb)


def run(alvik):
    middle = alvik.get_distance()[2]          # cm to whatever is straight ahead, or None for nothing
    if middle is not None and middle < TOO_CLOSE_CM:
        lights(alvik, SCARED)
        alvik.drive(-BACK_SPEED, 0)           # backwards, without turning
    else:
        lights(alvik, CALM)
        alvik.brake()
    sleep_ms(50)

sketch.json

{
  "title": "Scaredy cat",
  "emoji": "🙀",
  "description": "Sits still until something comes close, then backs away from it.",
  "color": [0, 1, 1],
  "hardware": ["distance sensors", "wheels", "lights"],
  "entry": "scaredy_cat"
}

"color": [0, 1, 1] is green and blue together: cyan. "entry" is the name of your .py file, without the .py.

Put it on the robot

The folder has to end up on the robot as /sketches/scaredy_cat/. Three ways, easiest first:

  • Just to see it: the finished one is already in the extras on the update page as 🙀 Scaredy cat.
  • Arduino Lab for MicroPython: connect, open the robot's files, make a folder scaredy_cat inside sketches (make sketches too if it isn't there), and save your two files into it. Switch the robot off and on.
  • A terminal, with mpremote installed: 
    mpremote fs mkdir :sketches
mpremote fs cp -r scaredy_cat :sketches/ + reset
    (The first line complains if the folder is already there. That is fine.)

Then on the robot: ⬆ until the lights are cyan, and ✓. Green means calm. Bring your hand to its nose.

🧪 Try this

  • Break it on purpose. Change TOO_CLOSE_CM to 20 and put the robot on an empty floor. What does it do, and why? (Lesson 5 has the answer.)
  • Turn tail. Make it spin away instead of backing up: alvik.drive(0, 90).
  • Look both ways. alvik.get_distance() gives five numbers. Use the left and right ones to turn away from the side the scary thing is on.
  • A brave cat. Make one that creeps towards things instead, and stops just in time.
  • Crash it. Spell brake wrong and run it. Count the red flashes. The robot also prints which line went wrong down the USB cable: the README says how to read it.

✏️ Make your own

Now invent one. A robot that turns to face the brightest colour? One that draws a square, or refuses to cross a black line? The Alvik commands used in this project are a good start: drive, brake, get_distance, get_line_sensors, get_color, left_led.set_color, and get_touch_ok for the ✓ button. The full list is in Arduino's Alvik guide.

The rules for a sketch that other people can install from the update page are in the README.
