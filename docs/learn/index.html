📚 Alvik lessons 🎮 Pretend robot 🤖 Remote

Drive a robot, then see what it senses

Nine short lessons with the Arduino Alvik robot. You start with a robot that does nothing new and end with one you drive from a web page, while a live 3D robot on the screen shows what its sensors see. One sensor comes online in each lesson, the way it did when we built it.

🎮 No robot? Start anyway

Every lesson from 2 to 7 also works with a pretend robot that lives in the web page. It takes the same messages as the real one and sends the same answers back, so nothing in the lessons changes.

🧭 How the lessons work

Each one is for a single sitting, and each has the same parts:

  • ▶️ Do it: steps to follow, with the robot on the floor.
  • 🔍 How it works: what is going on inside, with the real code.
  • 🧪 Try this: small experiments. Guess what will happen first, then look.
  • ✏️ Change it: one thing to change in the code, for when you want to go further.

They were written by a family, for a grown-up and a child to do together (ours started at about eight). You can also just read them to see how the remote works. Lessons 1 to 7 need nothing but a browser. Their optional "peek with code" boxes, and lesson 8, use Arduino Lab for MicroPython, the free editor from Arduino that most Alvik owners already have.

🧰 What you need

  • An Arduino Alvik, charged, running MicroPython as it comes out of the box.
  • A USB-C cable and a computer with Chrome or Edge, to put the code on the robot (lesson 1).
  • Something to drive with: an Android phone or tablet, a Chromebook, or a Mac or Windows laptop, with Chrome or Edge. On an iPad or iPhone, the free Bluefy browser.
  • For later lessons: a clear bit of floor, a box, a few sheets of coloured paper and some black tape.
