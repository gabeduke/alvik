📚 Alvik lessons

Drive a robot, then see what it senses

Nine short lessons with the Arduino Alvik. Drive it from a web page, and add one sensor per lesson to a live 3D robot on the screen.

🎮 No robot? Start anyway

Lessons 2 to 7 also work with a pretend robot in the web page.

🧭 How the lessons work

Each lesson has ▶️ Do it (steps), 🔍 How it works (the real code), 🧪 Try this and ✏️ Change it. Made for a grown-up and a child together.

🧰 What you need

  • An Arduino Alvik, charged, and a USB-C cable.
  • Chrome or Edge on a computer, phone or tablet. On iPad or iPhone, the free Bluefy browser.
  • Later: some floor, a box, coloured paper and black tape.
Lessons for the Alvik remote. The code is on GitHub. Found a mistake? Tell us. Not made by or connected with Arduino.
