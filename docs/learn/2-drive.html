🕹️ Drive it

Drive the robot over Bluetooth, then see what the page sends: five bytes at a time.

🧰 You need

  • The robot from lesson 1, on the floor.
  • Chrome or Edge on a phone, tablet or laptop (iPad/iPhone: Bluefy).
🤖 Open the remote 🎮 No robot: use the pretend one

▶️ Do it

  1. On the robot, pick purple and press ✓. Yellow lights = waiting.
  2. Press Connect and pick Alvik.
  3. Drag the joystick. A little = slow, a lot = fast.
  4. Try 💡 Lights, 🚀 Turbo and 🪩 Disco.
  5. Laptop: arrow keys or WASD, and 1–4 for buttons.

One remote at a time. While connected, nobody else can find the robot.

🔍 How it works

Every message is a packet of five bytes (numbers 0 to 255):

!startBbutton3which one11 down, 0 up8checksum
!startJjoystickx-100 to 100y-100 to 100?checksum

The last byte is a checksum: add the first four, flip the bits. If the robot's sum doesn't match, the packet got garbled and it is thrown away.

Make a packet

The check on the robot, in remote_control.py:

pkt = buf[i:i + 5]
if (~sum(pkt[:4])) & 0xFF != pkt[4]:
    buf = buf[i + 1:]                  # damaged: look for the next '!'
    continue

🧪 Try this

  • Checksum by hand. Lights down is 33, 66, 49, 49. Add them and take the total from 255. Does it match the packet maker?
  • Negative bytes. Slide the stick to -1. Why does the byte show 255?
  • Walk away with the phone while driving. What does the robot do? (Lesson 3.)
