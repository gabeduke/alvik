🔧 Wake up the robot

Put this project's code on your Alvik from the browser, then meet the colour menu.

🧰 You need

  • Your Alvik, charged and switched on.
  • A USB-C cable that carries data (some only charge).
  • A computer with Chrome or Edge. Phones can't do this step.

This replaces the robot's menu program. Its three built-in programs stay. To go back, copy examples/demo onto the robot.

▶️ Do it

  1. Close Arduino Lab for MicroPython if it is open.
  2. Open 🔧 Update the robot.
  3. Plug in the robot, press 🔌 Connect USB and pick it.
  4. Optional: under ✨ Extras, tap ＋ Add on any you like.
  5. Press ⚡ Update the robot. It restarts by itself.
  6. Lights go blue: that is the menu. Unplug it.

🚦 The colour menu

⬆ ⬇ change colour, ✓ runs it, ✗ goes back.

LightsProgramWhat it does
🔴 redTouch-moveTap arrows to line up moves, ✓ to run them.
🔵 blueLine followerFollows a black line. The menu starts here.
🟢 greenHand followerKeeps about 10 cm from your hand.
🟣 purpleRemoteDrive it from a phone (lesson 2).
⚪ white, 🟡 yellow…Your extrasOne colour each.

Programs come in pages of six. On page 2 the light blinks once every two seconds, on page 3 twice.

🔍 How it works

The robot runs MicroPython. At power-on it runs main.py, which is just import demo. demo.py is the menu: a list of colours and programs.

MENU = [            # (colour, program)
    (RED, run_touch_move),
    ((0, 0, 1), run_line_follower),
    ((0, 1, 0), run_hand_follower),
    ((1, 0, 1), run_remote),
]

A colour is (red, green, blue). (1, 0, 1) is purple. The update page sends each file down the cable and checks a checksum so nothing gets lost.

🧪 Try this

  • Program a square. Red, ✓, then ⬆ ➡ ⬆ ➡ ⬆ ➡ ⬆ ➡ and ✓. Does it end where it started?
  • Make a track. Black tape on a pale floor. Blue, ✓, robot on the line.
