🔧 Wake up the robot

Put this project's code on your Alvik, straight from the browser. Then meet the colour menu: the robot's lights show which program you are about to run.

🧰 You need

  • Your Alvik, charged and switched on.
  • A USB-C cable. It has to carry data: some cables only charge.
  • A computer with Chrome or Edge (Mac, Windows, Linux or Chromebook). Phones and tablets can't do this step.

This replaces the robot's own menu program with this project's. The three programs your Alvik came with (touch-move, line follower, hand follower) are still in it, and the Alvik library on the robot is not touched. To go back to Arduino's own, copy the files from examples/demo in arduino-alvik-mpy onto the robot.

▶️ Do it

  1. Close Arduino Lab for MicroPython if it is open. Only one program can use the USB cable at a time.
  2. Open the 🔧 Update the robot page on the computer.
  3. Plug the robot in and switch it on. Press 🔌 Connect USB and pick the robot in the list.
  4. Under ✨ Extras, tap ＋ Add on any you like. Each one becomes a new colour in the robot's menu.
  5. Press ⚡ Update the robot and wait. Each file is copied, then checked. The robot restarts by itself.
  6. The lights go blue. That is the menu. Unplug the cable and put the robot on the floor.

🚦 The colour menu

On top of the robot are touch buttons. ⬆ and ⬇ change the colour, ✓ runs that program, and ✗ comes back to the menu.

LightsProgramWhat it does
🔴 redTouch-moveTap the arrows to line up moves, then ✓ to run them.
🔵 blueLine followerFollows a black line on a pale floor. The menu starts here.
🟢 greenHand followerKeeps about 10 cm from your hand: forwards and backwards.
🟣 purpleRemoteWaits for a phone or laptop to drive it. That is lesson 2.
⚪ white, 🟡 yellow…Your extrasOne colour each, after purple: white is Disco, yellow is Follow me.

More than six programs? They come in pages of six. On the second page the light blinks off once every two seconds, on the third page twice.

🔍 How it works

The Alvik has a small computer that runs MicroPython: Python for tiny computers. Its programs are ordinary .py files stored on the robot. When you switch it on it runs the file called main.py, and ours is one line long:

import demo

demo.py is the colour menu. It is a list of colours and programs, and a loop that watches the touch buttons:

MENU = [            # (colour, program)
    (RED, run_touch_move),
    ((0, 0, 1), run_line_follower),
    ((0, 1, 0), run_hand_follower),
    ((1, 0, 1), run_remote),
]

A colour is three numbers: how much red, green and blue. (1, 0, 1) is red and blue together, which makes purple.

The update page talks to the robot down the USB cable. It does what a person would do at the robot's Python prompt, only faster: it stops whatever is running, sends each file, asks the robot to work out a fingerprint of what it saved (a checksum), compares that with the fingerprint of the file it sent, and restarts the robot. If one letter got lost on the way, the fingerprints would not match.

🧪 Try this

  • Program a square. Go to red, press ✓, then tap ⬆ ➡ ⬆ ➡ ⬆ ➡ ⬆ ➡ and press ✓. Does it end where it started? Why not quite?
  • Make a track. Stick black tape on a pale floor, or draw a thick black line on paper. Blue, ✓, and put the robot on the line.
  • Look at the log. On the update page, open Log at the bottom and update the robot again. You can read every message that goes down the cable.
  • Count the colours. How many different colours can two lights make if each of red, green and blue is only on or off? (One of them is "off".)
