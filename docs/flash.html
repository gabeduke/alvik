This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer (Mac, Windows, Linux or Chromebook). iPad, iPhone and Android can't flash the robot.

Before you start

  • This copies the robot code from this website onto the Alvik over a USB-C cable, then restarts it into the colour menu.
  • Chrome or Edge on a computer only. iPad and Android phones can't do this.
  • Close Arduino Lab for MicroPython (and Thonny, mpremote or any serial monitor) first: only one program can use the USB port.
  • “Port busy” or “couldn't open”? Close the other program, unplug the cable, plug it back in and press Connect again.
  • It works even if the robot is stuck: it stops whatever is running first.
  • A sketch is an extra program for the menu. Flashing one also updates the menu itself. After the restart, press ⬆ until you see the sketch's colour, then ✓.
