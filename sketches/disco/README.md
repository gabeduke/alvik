# 🪩 Disco

The robot throws a party: the lights flash different colours on each side, it wiggles left and
right to the beat, then finishes with a big spin. It's the same dance as button 3 on the phone
remote (the code is in `src/dance.py`, so both stay the same).

- **Menu light:** white
- **Buttons:** ✓ dance again (the lights go white while it waits) · ✗ back to the menu
- **Uses:** wheels, lights. Give it some room on the floor.

Things to try: change `DANCE_MS`, `WIGGLE` or the colours in `src/dance.py`.
